# FunSearch comparison materials: partial source only

`candidate_programs.txt` preserves the candidate function text available in the
research materials. It is executable-program evidence, not a complete FunSearch
search implementation, a complete experiment protocol, or a formal result table.

No full FunSearch runner was located in the supplied code handoff. This package
does not invent one or rebrand EoH/ReEvo as the main comparison. The verified
runner, sampling/evaluation budget, configuration, candidate-selection provenance,
and corresponding data contract must be added before claiming an end-to-end
reproduction of that comparison.
